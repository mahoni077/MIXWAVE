MIXWAVE — PWA-прототип для Android

ЧТО УЖЕ ЕСТЬ
- Интерфейс музыкального приложения.
- Загрузка трендовых треков Audius.
- Поиск по каталогу Audius.
- Воспроизведение потока через HTML audio.
- Локальные избранное и история.
- Настройка Audius API key внутри приложения.
- PWA manifest и service worker.

ВАЖНО
Это первый рабочий каркас, а не готовый APK и не интеграция с полными каталогами SoundCloud/VK.
Доступность конкретного трека и потокового URL определяет Audius и права на трек.
Ключ вводи только в настройках установленной личной копии. Не отправляй его в чат и не коммить в публичный репозиторий.

КАК ЗАПУСТИТЬ С ТЕЛЕФОНА
PWA устанавливается через HTTPS. Открытие index.html из файлового менеджера не даст полноценную установку.

Самый простой способ:
1. Создай приватный репозиторий GitHub с названием MIXWAVE.
2. Загрузи в него ВСЕ файлы из этой папки (не сам ZIP).
3. В репозитории открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку main и папку /(root), затем Save.
6. Подожди публикации сайта; GitHub покажет адрес вида https://ТВОЙ-ЛОГИН.github.io/MIXWAVE/
7. Открой адрес в Chrome на Xiaomi.
8. Меню ⋮ → Установить приложение / Добавить на главный экран.

Если не хочешь хранить код публично, используй приватный репозиторий (проверь, что GitHub Pages доступен для твоего тарифа) или другой HTTPS-хостинг.

API KEY
Открой MIXWAVE → ⚙ → вставь ключ Audius → Сохранить.
Ключ хранится в localStorage браузера на этом устройстве. Это удобно для личного прототипа, но не является серверной защитой секрета.

ЕСЛИ НЕ ГРУЗИТ МУЗЫКУ
- Проверь интернет.
- Попробуй оставить API key пустым, если Audius публичные запросы разрешает без него.
- Если API требует другой формат авторизации или изменил endpoint, пришли текст ошибки из приложения — адаптируем интеграцию.
